# Tech Stack: Supra L1 SDK

## Core Language and Runtime
- **TypeScript:** The primary programming language for all code and examples.
- **Node.js:** The primary runtime for server-side execution.

## Core Libraries
- **axios:** For making HTTP requests to the Supra RPC nodes.
- **js-sha3:** For cryptographic hash generation.
- **supra-l1-sdk-core:** Core SDK logic and utilities.

## Build and Documentation Tools
- **tsup:** For bundling the SDK for different environments (Node.js and browser).
- **TypeScript Compiler (tsc):** For static type checking and compilation.
- **TypeDoc:** For generating high-quality documentation from the source code.
